- [项目状态](STATUS.md)：已确定事项、待确定事项和下一步。

## 跨设备使用

GitHub 仓库保存需要长期保留的文件。电脑端、Codex 云端和手机端继续工作时，先读取仓库最新版本。聊天中的结论需要写入文件，并通过提交或合并拉取请求同步到仓库，其他环境才能取得这些更新。

ChatGPT 项目可以整理策划聊天和上传资料；它不会自动将本地文件夹或所有仓库改动同步成项目资料。使用时需连接相应来源或上传最新文件。

大型视频、音频和工程素材放在单独的素材存储中，仓库记录链接、版本和用途。当前仓库公开，写入前按公开内容处理。

节目定位、主要平台、受众、风格与更新频率尚待确定。
